> **"지식의 파편을 모아 깊이를 더하다"**  
> 기술 유튜브 영상, 아티클, 블로그 글을 읽고 핵심을 분석하며, 깊이 있는 후기와 꼬리 질문을 통해 함께 소통하는 공간입니다.


## 학습 목표
- 양질의 기술 영상 및 아티클을 정독하고 기록한다.
- 읽기만 하는 것이 아니라, **실무 적용점**과 **예상 면접 질문**을 도출한다.
- 동료의 기록에 피드백과 꼬리 질문을 남기며 기술적 소통 역량을 키운다.

## 활동 방식 (How to run)

1. **컨텐츠 선정:** 매주 함께 분석할 기술 아티클이나 유튜브 영상을 선정합니다.
2. **리뷰 작성 (Issue):** 해당 컨텐츠를 보고 느낀 점, 핵심 요약, 의문점을 본 레포지토리의 `Issue` 탭에 작성합니다.
3. **상호 리뷰 (PR/Comment):** 다른 멤버가 작성한 글에 의견을 달거나, 실제 면접이라 가정하고 압박 질문(꼬리 질문)을 남기며 토론을 이어갑니다.
